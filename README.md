# Python Fake User Generator

Faker kütüphanesi kullanılarak Türkçe rastgele test kullanıcıları oluşturan basit bir Python uygulamasıdır.

## Kullanılan Kütüphane

- Faker

## Özellikler

- Rastgele isim oluşturur.
- Rastgele telefon numarası oluşturur.
- Rastgele e-posta oluşturur.
- Rastgele şehir oluşturur.
- İstenilen sayıda test kullanıcısı üretir.
